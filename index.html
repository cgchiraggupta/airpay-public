hi, this is airpay.

it's an offline-capable upi app we built for low-connectivity environments.

one simple, clean place to scan a qr, enter a upi id, and complete a payment even when internet access is weak or unavailable. airpay uses a device-side session management layer, automates the bank interaction flow on-device, and stops at the pin step so the user still enters credentials in the bank prompt.

built around qr scanning, device-side flow orchestration, balance checks, and local-first transaction history.
